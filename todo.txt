1. La création de la classe ModelAndView

Tu dois créer une classe chargée de transporter à la fois le nom de la vue et les données du modèle. Elle doit posséder :

    Un attribut pour la vue (ex: String view).

    Une structure pour stocker les données (une HashMap).

    La méthode exacte spécifiée : setAttribut(String, Object) (ou setAttribute selon la casse de ton sujet) pour y ajouter des données.

    Une méthode pour définir la vue (ex: setView(String)).

2. La configuration des paramètres dans web.xml

Tu dois ajouter des paramètres d'initialisation (<init-param>) spécifiques à ta FrontServlet dans ton fichier de configuration pour externaliser les extensions et les dossiers :

    view.prefix : Le dossier où se trouvent tes fichiers de vue (ex: /WEB-INF/jsp/).

    view.suffix : L'extension de tes fichiers (ex: .jsp).

3. La récupération et l'aiguillage dans FrontServlet

Dans la méthode init() de ton servlet, tu dois récupérer ces deux paramètres. Ensuite, lors du traitement de la requête (processRequest) :

    Si la méthode de ton contrôleur renvoie un objet ModelAndView :

        Tu extrais toutes les données stockées dans sa Map et tu les injectes dans les attributs de la requête (request.setAttribute(clé, valeur)).

        Tu construis dynamiquement le chemin final vers la vue : prefix + view + suffix.

        Tu passes le relais à cette vue en faisant un forward (request.getRequestDispatcher(...).forward(request, response)).

4. Le test dans le contrôleur (Données en dur)

Tu dois écrire une méthode de test (souvent nommée list()) associée à une annotation @UrlMapping qui :

    Instancie un objet ModelAndView.

    Crée une donnée fictive en dur (comme une liste ou un objet).

    Envoie cette donnée à la vue via mv.setAttribut("nom", donnee).

    Spécifie la vue cible via mv.setView("nomDeLaVue").

    Retourne l'objet ModelAndView.
